# Kinektic

Desktop installers for Kinektic, a 2D motion design and animation tool. The latest version:

| | |
| --- | --- |
| **Windows** (64-bit) | [Kinektic-win-x64.exe](https://github.com/ReljaT/kinektic-releases/releases/latest/download/Kinektic-win-x64.exe) |
| **macOS, Apple silicon** (M1 and later) | [Kinektic-mac-arm64.dmg](https://github.com/ReljaT/kinektic-releases/releases/latest/download/Kinektic-mac-arm64.dmg) |
| **macOS, Intel** | [Kinektic-mac-x64.dmg](https://github.com/ReljaT/kinektic-releases/releases/latest/download/Kinektic-mac-x64.dmg) |

Every version is on the [Releases](https://github.com/ReljaT/kinektic-releases/releases) page.

## Opening it the first time

These test builds are not signed yet, so the system asks once:

- **Windows:** SmartScreen says it protected your PC. Click **More info → Run anyway**.
- **macOS:** drag Kinektic to **Applications** and open it. When macOS says it cannot verify
  the developer, go to **System Settings → Privacy & Security** and click **Open Anyway**
  (on macOS 14 and earlier, right-click the app and choose **Open**).

This repository holds the installers only.
